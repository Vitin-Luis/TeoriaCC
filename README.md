# Teoria de Computação - 5º Período
Repositório designado para a disciplina de **Teoria da Computação** do 5º período.

## Conteúdo
Este repositório contém arquivos relacionados à disciplina, em especial:

- Arquivos do tipo `.jflap`, utilizados no software **JFLAP 8 Beta**.
- Máquinas de Turing.
- Autômatos finitos (determinísticos e não-determinísticos).
- Outros modelos computacionais utilizados para estudo e simulação.

## Software Recomendado

Para utilizar os arquivos contidos aqui, é necessário o software:

- **[JFLAP 8 Beta](https://www.jflap.org/)**: Ferramenta educacional usada para simular autômatos, gramáticas, máquinas de Turing, e outros conceitos de teoria da computação.

## Finalidade

Estes arquivos têm como objetivo:

- Apoiar os estudos e revisões dos conteúdos vistos em aula.
- Servir como base para experimentação prática com modelos formais.
- Ajudar na visualização do funcionamento de autômatos e máquinas de Turing.
